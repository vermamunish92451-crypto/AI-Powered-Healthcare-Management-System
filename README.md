# Healthcare Management System
## AI-Powered Disease Prediction & Recommendation System

---

## Project Overview
This is an **Artificial Intelligence** based Healthcare Management System that:
- Predicts diseases based on patient symptoms (99.5% accuracy)
- Provides prescription and medicine recommendations
- Suggests personalized diet plans
- Recommends workout routines
- **NEW:** AI Health Chatbot for instant health advice
- **NEW:** PDF report download
- **NEW:** Dark mode support
- **NEW:** Share reports on social media

---

## Tech Stack

| Technology    | Purpose                          |

## Features

### Core Features
- Disease Prediction with 99.5% accuracy
- 41 diseases covered
- 130+ symptoms in database
- Medicine recommendations
- Diet plan suggestions
- Workout routine recommendations

### New Features (v2.0)
- **AI Health Chatbot** - Get instant health advice
- **PDF Report Download** - Download health reports as PDF
- **Dark Mode** - Toggle between light and dark themes
- **Share Reports** - Share reports on WhatsApp, Twitter, Email
- **User Registration** - Register and track your health history
- **BMI Calculator** - Calculate BMI with health score

## How to Run

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
streamlit run app.py
```

3. Open browser at `http://localhost:8501`
